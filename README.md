# Weather ML Comparison

This project analyzes a weather dataset using machine learning techniques in **R**. It implements and compares two classification models: **Decision Tree** and **Random Forest**.

## 📌 Project Overview

The main objective of this project is to apply machine learning algorithms to a weather dataset and compare their performance.

### Models Used

* Decision Tree
* Random Forest

## 🛠️ Technologies Used

* R
* RStudio
* Machine Learning
* Decision Tree
* Random Forest

## 📊 Project Workflow

1. Load the weather dataset
2. Explore and preprocess the data
3. Split the dataset into training and testing sets
4. Train a Decision Tree model
5. Train a Random Forest model
6. Evaluate both models
7. Compare their performance

## 📈 Model Comparison

The performance of the Decision Tree and Random Forest models is compared using suitable evaluation metrics.

## 🚀 How to Run

1. Install **R** and **RStudio**.
2. Clone or download this repository.
3. Open the `.R` file in RStudio.
4. Place the weather dataset in the project folder.
5. Run the R script.
